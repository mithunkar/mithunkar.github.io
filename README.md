# Mithun Karthikeyan - Personal Portfolio

A static Astro portfolio published at [mithunkar.github.io](https://mithunkar.github.io).

## Local development

Run npm install, then npm run dev.

## Updating project images

Replace the placeholder files in public/images/projects while preserving their filenames. Images use a 16:9 crop.

## Publishing

Pushes to main are built and deployed to GitHub Pages by .github/workflows/deploy.yml.
